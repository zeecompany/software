What was fixed
==============
Employee PPE Register would not start on databases created by older
versions (v22 and earlier) with the error:

    sqlite3.OperationalError: no such column: batch_id

Root cause: the v24 schema added a batch_id column to the records table AND
an index on that column inside the DDL. The index creation ran before the
migration that adds batch_id to old databases, so SQLite failed and the
whole application could not start.

Fix: the batch_id migration now runs first (in _apply_schema_fixes) and the
batch index is created afterwards. Existing PPE data is preserved and the
migration is idempotent.
